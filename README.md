# GT Cosmetic Catalog

BepInEx plugin for the **Steam version of Gorilla Tag** that displays the loaded cosmetic registry in an in-game catalog.

> Steam only for now. The mod has not been tested on the standalone or Quest version.

## Features

- Toggle the catalog with `F8`.
- Search available cosmetics.
- View cosmetic names, IDs, categories, and prices.
- Add item(s) to Gorilla Tag's normal shop cart.
- Buying item(s) through the UI.
